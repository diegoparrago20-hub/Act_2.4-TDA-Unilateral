# Act_2.4 Lista Unidireccional de Aviones
Este proyecto consiste en el desarrollo de un Tipo de Dato Abstracto (TDA) Lista Unidireccional en Java, utilizando nodos y una interfaz gráfica desarrollada con Java Swing en NetBeans.
La lista permite administrar registros de aviones y realizar operaciones para insertar, eliminar, buscar y mostrar elementos. Cada nodo mantiene una referencia al siguiente nodo de la lista.

# Objetivo

Implementar una lista unidireccional mediante nodos, aplicando los conceptos de estructuras de datos y programación orientada a objetos, con una interfaz gráfica que facilite la interacción con el usuario.

# Tecnologías utilizadas
Java
Java Swing
Apache NetBeans
Git y GitHub

# Funcionalidades
Insertar aviones al principio, al final y en una posición específica.

Eliminar aviones del principio, del final y de una posición específica.

Mostrar el primer y el último elemento.

Buscar aviones por valor o posición.

Recorrer y visualizar los elementos de la lista.

Vaciar la lista y comprobar si está vacía.

Validar los datos ingresados por el usuario.

# Estructura del proyecto

El proyecto se organiza en tres partes principales:

Record Avion: representa los datos de cada avión.

Nodo: almacena un avión y la referencia al siguiente nodo.

ListaUnidireccional: implementa las operaciones de la lista.

Interfaz gráfica: permite utilizar las operaciones mediante formularios y botones.
